# Grammar provenance

The grammars in this directory are TextMate grammars (JSON) taken unchanged in content from
[`@shikijs/langs`](https://github.com/shikijs/shiki/tree/main/packages/langs) 4.4.3 (MIT, Copyright (c) 2021 Pine Wu, Copyright (c) 2023
Anthony Fu), the registrations dsh web's highlighter loads. shiki builds them from the
[shikijs/textmate-grammars-themes](https://github.com/shikijs/textmate-grammars-themes) collection, which records for
every grammar the file it was taken from (`source`, pinned to a commit) and that file's licence. Most are VS Code
extension copies in [microsoft/vscode](https://github.com/microsoft/vscode) (MIT, Copyright (c) 2015 - present
Microsoft Corporation) that say which repository they were converted from; the "Upstream" column names that
repository, the licence of its `LICENSE` file and its copyright line. The upstream was read on 2026-10-24.

`tool/highlight/convert.mjs` writes the files: one per registration (shiki's modules repeat embedded dependencies in
every language that uses them; here each is stored once and `embeddedLangs` names it), keeping only the keys the
engine reads (`name`, `scopeName`, `patterns`, `repository`, `injections`, `injectionSelector`, `injectTo`,
`embeddedLangs`) and dropping the authors' free-text `comment` strings. Rules and regexes are not edited.
`index.json` is generated by the same script (names, scope names, sizes, embedded dependencies).

Licence texts are in the repository's `THIRD_PARTY_NOTICES.md`. "TextMate bundle notice" is the permission notice
of the textmate/*.tmbundle repositories ("Permission to copy, use, modify, sell and distribute this software is
granted ...", reproduced there); it is permissive but is not MIT, Apache, BSD or OFL wording. Those five grammars
(`diff`, `html`, `ini`, `toml`, `yaml`) can be dropped by listing them under `withheld` in
`tool/highlight/languages.json` and re-running the converter.

Not shipped: `glsl` (an optional embedding of `cpp`; its upstream polym0rph/GLSL.tmbundle states no licence).
